# 字幕校验与对轴流程

## 处理顺序

1. 解析 MoviePilot 或 Jellyfin 提供的媒体路径。
2. 检查同目录外挂中文字幕。
3. 使用 ffprobe 检查视频内嵌字幕流。
4. 匹配整季包缓存；未命中时才等待字幕源搜索槽位。
5. 按字幕源优先级搜索并排序候选。
6. 下载候选，安全解压并选择目标文件。
7. 校验文本编码、字幕结构、中文内容、电影年份和剧集季集信息。
8. 使用 ffsubsync 对轴；低质量结果会拒绝并继续下一个候选。
9. 写入媒体目录，记录来源和文件身份，并刷新 Jellyfin 缓存中的字幕状态。

## 文本与压缩包

支持 SRT、ASS、SSA、VTT，文本编码包括 UTF-8、GB18030、Big5，以及带 BOM 的
UTF-16、UTF-32。ZIP 使用 Python 标准库读取；RAR、7z 通过容器内的安全列表和
解压工具处理。压缩包会限制成员数量、解压总大小和路径，拒绝目录穿越。

## 当前对轴方式

拾幕把完整视频路径和候选字幕交给 ffsubsync，并设置 15 分钟超时。当前没有实现
自定义的“取字幕中段、截取一小段音频”抽样，也不会预先生成一份完整音频文件。
ffsubsync 通过 ffmpeg 流式读取视频音频，提取语音活动时间线，再与字幕对白时间线
计算偏移和帧率比例。

当前命令启用 `--skip-sync-on-low-quality`：当分数、偏移量或帧率变化不可信时，
该候选不会落库，而是继续尝试下一个候选。命令同时带有 `--skip-intro-outro`，但在
当前未启用 ffsubsync 多段抽样模式时，该参数不改变完整视频处理范围。

## 对轴不能证明影片身份

ffsubsync 的分数表示两条“语音活动时间线”能否对齐，不是内容语义或影片身份校验。
错误影片仍可能因为对白节奏相似而得到可接受分数。因此拾幕会先使用媒体 ID、标题、
年份、季集和文件名过滤明显错误，再把 ffsubsync 作为最后的同步质量信号。
